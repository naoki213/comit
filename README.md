# comit

大きな目標と、毎日のコミットを管理する目標管理アプリ（ver2 / PWA）。

## 機能
- 起動時のロード画面（スプラッシュ）
- 大きな目標を作成（タイトル・期限）。右下の＋で複数作成でき、左右フリックで切り替え
- 大きな目標ごとに「毎日の目標（くり返し）」と「今日だけの目標」を追加
- タップでコミット。達成状況をリング・7日間の表示・連続日数・コミット履歴（5週間）で表示
- 曜日欄は日曜はじまりの週単位で左右スクロール（目標を作った週〜期限の週）。日付をタップして過去にコミット、未来の「今日だけの目標」を予定として登録
- 過去の未完了の「今日だけの目標」は「やり残し」として表示し、今日へ移動か削除を選べる
- 毎日の目標はアーカイブ可能（記録は残り、復元もできる）
- データは端末内（localStorage）に保存。右上のメニューからバックアップの書き出し・復元ができる
- ログイン不要・オフライン対応

## 使い方（ローカルで確認）
```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
スマホでは HTTPS で公開したURL（GitHub Pages など）を開き、「ホーム画面に追加」するとアプリとして使えます。

## ファイル構成
- `index.html` / `style.css` / `app.js` … アプリ本体
- `manifest.webmanifest` / `sw.js` … PWA設定・オフライン対応
- `assets/` … スプラッシュ画像・ロゴ
- `icons/` … アプリアイコン
